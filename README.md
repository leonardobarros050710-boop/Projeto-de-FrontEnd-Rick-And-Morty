# 🛸 Rick and Morty Explorer

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-end, com o objetivo de praticar HTML, CSS e JavaScript por meio do consumo de uma API externa.

O **Rick and Morty Explorer** permite explorar personagens do universo da série Rick and Morty, exibindo informações obtidas diretamente da API.

## 🚀 Funcionalidades

- **Listagem de personagens:** exibição dinâmica dos personagens recebidos da API.
- **Imagens:** apresentação das imagens correspondentes a cada personagem.
- **Status:** identificação do estado de cada personagem (Vivo, Morto ou Desconhecido), com cores diferentes.
- **Pesquisa:** busca de personagens pelo nome.
- **Paginação:** navegação entre as páginas de resultados da API.
- **Layout responsivo:** interface adaptável a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da página.
- **CSS3:** estilização, organização dos cards e responsividade.
- **JavaScript:** consumo da API, manipulação do DOM e implementação das funcionalidades.

## 🌐 API utilizada

O projeto utiliza a [Rick and Morty API](https://rickandmortyapi.com/), uma API pública que disponibiliza informações sobre personagens, episódios e localizações da série.

A comunicação com a API é realizada por meio do método `fetch()` do JavaScript, utilizando requisições HTTP para obter os dados em formato JSON.

**Documentação oficial:** https://rickandmortyapi.com/documentation

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado em formato ZIP.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo `index.html` utilizando a extensão Live Server ou abra-o diretamente no navegador.
5. Certifique-se de estar conectado à internet para permitir o carregamento dos dados da API.

## 🎯 Objetivo acadêmico

Este projeto tem como finalidade aplicar conhecimentos fundamentais de desenvolvimento front-end, especialmente o consumo de APIs externas, a manipulação dinâmica do DOM e a construção de interfaces utilizando HTML, CSS e JavaScript.
